# Workflow dashboard

This folder contains maintained HTML, CSS, and JavaScript. Generated data and report previews live in [reports/workflow](../../reports/workflow/README.md).

From the repository root:

```sh
npm run agentic:catalog
npm run agentic:kanban-data
npm run agentic:serve-kanban
```

Open `http://localhost:3456/docs/workflow/dashboard/kanban-board.html`. Also available: [task checklist](task-checklist.html), [monitoring](monitoring.html), and [workflow guide](panduan-alur.html).
