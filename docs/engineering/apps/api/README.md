# @invoicing/api

Backend HTTP JSON API (Remix router, tanpa UI). Port default **44101**.

## Endpoints (MVP scaffold)

| Method | Path | Deskripsi |
|--------|------|-----------|
| GET | `/api/health/live` | Liveness |
| GET | `/api/health/ready` | Readiness + DB |
| GET | `/api/v1/status` | Counts entity |
| GET | `/api/v1/clients` | Placeholder FR-01 |
