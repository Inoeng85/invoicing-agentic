# Laporan otomatis

Jalankan `npm run gate` dari root repository untuk menghasilkan ringkasan `gate-summary.md` dan laporan per gate di `gates/`. Output ini diabaikan Git dan tersedia setelah pemeriksaan dijalankan.

Panduan gate dan kesiapan rilis: [release readiness](../engineering/release-readiness.md). Laporan development, QA, dan audit task berada di [workflow/results](../workflow/results/README.md).

Generated dashboard snapshots and previews are documented in [workflow reports](workflow/README.md); maintained dashboard source remains in [workflow/dashboard](../workflow/dashboard/README.md).
