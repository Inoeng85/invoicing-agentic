Kenapa shadcn/ui?

Token semantik & varian komponen yang konsisten.

Kita memakai konvensi token dan resep class shadcn/ui. Komponen React-nya tidak dipakai langsung karena @invoicing/web berjalan di Remix 3 UI, bukan React.

Kenapa pola Tailwind UI?

Layout aplikasi SaaS yang teruji.

App shell, page heading, stats, dan list mengikuti pola Tailwind UI (Tailwind Plus). Markup ditulis ulang dari nol karena kode Tailwind Plus berlisensi berbayar.

Build

Tailwind CLI v4, tanpa CDN.

npm run design:css

Sumber: src/tailwind.css → assets/ui.css
