# Repository workflow

- `develop` is the default and integration branch.
- Perform every change on a `feat/*` branch created from the latest `develop`, including fixes, documentation, and infrastructure work.
- After completing and verifying the work, open a pull request and merge it into `develop`.
- Do not commit work directly to `develop` or `main`.
- Keep project documentation organized by purpose under `docs/`; use `docs/README.md` as the navigation index and update references when moving files.
